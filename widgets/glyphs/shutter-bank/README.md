# Tsugumori / Shutter bank

Small shutters slide open in staggered groups to reveal red plates. The browser preview and native QML component use the same drawing rules. Typing changes the pattern, deleting retraces it, and Enter or Unlock replays the red curtain.

This is an interactive visual study. It does not authenticate users, create a session lock, or unlock the desktop. Use dummy text in its demo field.

## Run

Download and extract the complete ZIP. Keep `Widget.qml`, its QML helpers, and `GlyphArt.js` together. With Quickshell 0.3.0 and Qt 6.11.2 installed, run:

```sh
qs -p /absolute/path/to/the/extracted-folder/shell.qml
```

The launcher opens a regular, resizable window. It uses Qt Quick, Qt Quick Controls Basic, and Qt Quick Layouts. It does not change desktop configuration or connect to authentication services. To embed the component in a QML layout:

```qml
import "./shutter-bank" as Glyph

Glyph.Widget {
    width: 354
}
```

The artwork fits above the input panel at narrow widths. The example window scrolls when its content is taller than the available space. JetBrains Mono is used for the interface. Japanese interface labels request Noto Sans CJK JP. System fonts provide fallbacks when those families are absent. No fonts, images, remote assets, or additional native libraries are bundled.

## Interaction and settings

Click the demo field or use Tab to focus it. Type, paste, use Backspace/Delete, or replace a selection. Input is limited to 64 UTF-16 units, matching browser string length. A committed edit is replaced with `x` placeholders. The artwork depends only on length; typed characters and their hashes never select its geometry. Input and selection stay in memory for this component's lifetime.

Enter and Unlock replay the curtain when the input is nonempty. Empty submission focuses the field and shows a prompt. Editing during replay dismisses the curtain. When replay finishes, the pattern and current length remain. Clearing the field returns to the original drawing.

Input transition sets the base travel time from 80 to 350 ms. Larger edits extend the transition up to 700 ms. Red emphasis adjusts the red tint from 65 to 100 percent. Input animation turns movement and the curtain transition on or off.

Appearance and timing changes preserve the input length. The browser also honors reduced-motion preferences. In native QML, use the animation setting to disable transitions. Hidden native components stop their pending movement and replay timers. Copied QML and ZIP downloads include the same settings snapshot.

## Host integration

`inputLength`, `phase`, and `previewing` expose the component's current visual state. `setInputLength(length)` supplies a bounded dummy length without passing text. `focusInput()` focuses the demo field. `replay()` runs the preview, and `previewRequested(length)` reports that action with only the current length. A host can observe these for visual coordination; the component performs no authentication.

`GlyphArt.js` is the original drawing algorithm extracted into a plain JavaScript helper used by both the sandboxed browser preview and the QML artwork. The QML template is generated by Chaldea's shared frontend generator.

## Native inspection

The generated default export and a customized export with 350 ms input transition, 65 percent red emphasis, and animation disabled were inspected with Qt 6.11.2. QtTest covered committed-input redaction, selection deletion, reversing and interrupting movement, replay completion and cancellation, the 64-unit limit, settings changes, and a 220 px component width. The generated QML passed `qmllint`, and the exported launcher loaded in Quickshell 0.3.0.

Rendered default-width and narrow components were reviewed with the offscreen software renderer. JetBrains Mono and Noto Sans CJK JP were available on the inspection host. This inspection did not cover compositor integration, GPU rendering, or authentication. Font rasterization can differ between Qt and the browser.
