# Tsugumori / Punch record

Narrow slots punch through scattered banks while a carriage moves between them. Type dummy text to change the glyphs, erase it to reverse them, and try the Unlock preview.

Extracted from the lockscreen study into the same compact glyph-and-input layout as the other Glyphs. The original artwork reacts only to dummy-input length. The clock, outer lockscreen layout, workspace strip, and restart/shutdown controls have been removed. The existing widget ID and appearance setting keys are preserved.

Typing, deletion, and the Unlock curtain remain local preview interactions. The input retains only bounded length and placeholder characters. Appearance settings preserve the current input length. This widget does not authenticate or control a desktop session.

This is one design from the owner-supplied `Lib-assests/lockscreen/tsugumori-mechanical-lockscreen-studies.html`. Distinct designs have separate library entries. Appearance settings remain controls.

Interactive HTML draft. Native QML and downloads are not implemented. Local development includes this entry; production builds omit drafts. Original widget code uses 0BSD.
