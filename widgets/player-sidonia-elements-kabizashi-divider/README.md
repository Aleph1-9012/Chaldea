# Tsugumori / Sidonia elements / Kabizashi divider

Play or pause the silent sample timeline, seek, switch tracks, and inspect the player artwork.

This is one design from the owner-supplied `Lib-assests/player/tsugumori-sidonia-elements.html`. Distinct designs have separate library entries. Appearance settings remain controls.
