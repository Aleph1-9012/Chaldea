# Tsugumori / Phase lock

HTML-only draft adapted from the owner's `Lib-assests/lockscreen/tsugumori-phase-formation-lock.html`. Original formation animation and layout are retained. Remote font imports were removed, the example username was replaced, and scripts were made local.

The input and unlock button demonstrate animation only. They do not authenticate or lock a desktop. Do not enter a real password. This draft has no QML, exported files, or native installation. It appears only in local builds that include drafts.
