# Tsugumori / Menu refinement preview

Search and select sample applications, then use the launcher controls. Launch actions are simulated.

This is one design from the owner-supplied `Lib-assests/menu/menu-refinement-preview.html`. Distinct designs have separate library entries. Appearance settings remain controls.

Interactive HTML draft. Native QML and downloads are not implemented. Local development includes this entry; production builds omit drafts. Original widget code and the preview adapter use 0BSD. No desktop services are connected.
