# Tsugumori / Glyph behaviours

Play or pause the silent sample timeline, seek, switch tracks, and inspect the player artwork.

This is one design from the owner-supplied `Lib-assests/player/tsugumori-glyph-behaviours.html`. Distinct designs have separate library entries. Appearance settings remain controls.

Interactive HTML draft. Native QML and downloads are not implemented. Local development includes this entry; production builds omit drafts. Original widget code and the preview adapter use 0BSD. No desktop services are connected.
