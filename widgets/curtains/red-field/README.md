# Red field curtain

The Red field curtain design from the owner-supplied `Lib-assests/curtains-and-buttons/curtain-design-studies.html`, available as its own widget in Chaldea.

## Try it

Replay or pause the curtain animation, scrub the reveal, and try it over the Menu and Player samples.

Use the controls inside the preview. Settings below it adjust this design. State stays in memory and resets when you leave. Fonts and icons are local, with no external requests.

## Implementation status

Interactive HTML draft. Native QML, desktop integration, authentication, and widget export are not implemented. `make dev` includes this preview; production builds omit it. Original widget code and local icon markup use 0BSD.

Source SHA-256: `db2da944fd72b8a76d460c81428e0223fba32b1312cc4705df4c3c2ae6f90fed`. The source archive is unchanged. This widget extracts one design, keeps its direct interactions, and connects its settings to the sandbox preview runtime.
